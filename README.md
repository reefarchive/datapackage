# Reef Archive Data Package

The Reef Archive Data Package (RADP) is a standard format for sharing historical reef photographs and videos, along with the metadata that describes them.

## Usage

See project website: [https://www.reefarchive.org](https://www.reefarchive.org)

## Contribute

Have a question, a suggestion, or a correction? We welcome contributions to the Reef Archive Data Package.

- **Ask or suggest:** Open an issue on the repository, or join an existing discussion.
- **Stay informed:** Watch the repository to follow updates and new issues.
- **Contribute directly:** Fork the repository and submit a pull request.
